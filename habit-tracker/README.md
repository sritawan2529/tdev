# CEO Habit OS v1

เว็บแอปขนาดเล็กสำหรับโฟกัสสิ่งสำคัญในแต่ละวันและติดตาม Habit โดยไม่ต้องมี Backend

## Features
- Top 3 Today
- Daily Habits
- Daily Score
- Current / Best Streak
- Evening Reflection
- Dark Mode
- Responsive
- เก็บข้อมูลด้วย LocalStorage

## Run
เปิดไฟล์ `index.html` ใน browser ได้ทันที

## GitHub Pages
Repo นี้ใช้โฟลเดอร์ `habit-tracker/` ดังนั้นถ้าเปิด GitHub Pages จาก root ของ repo ให้เข้าผ่าน `/habit-tracker/`
